## The premise

Personal color analysis — figuring out which seasonal palette flatters you — is
usually a paid, in-person session. I wanted to see how much of it could happen
right in the browser, instantly, with nothing leaving your device.

## What I explored

- **Camera as input.** Using on-device computer vision to find a face and sample
  the tones that actually matter — skin, hair, eyes — from a live webcam frame.
- **From tones to a palette.** Turning those samples into a seasonal reading and a
  suggested palette, presented simply enough to be useful rather than clinical.
- **Privacy by architecture.** Because the vision model runs locally, the analysis
  happens on-device — the camera frame doesn't need to go anywhere.

## How it's built

A Vite + React app in TypeScript, using MediaPipe's vision tasks for on-device
face and landmark detection, with a Radix UI component layer for the interface.

This was mostly an excuse to get my hands dirty with real-time computer vision in
the browser — and to see how close a free, instant, private tool could get to
something people normally pay for.

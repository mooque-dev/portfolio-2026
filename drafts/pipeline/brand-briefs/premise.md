# Premise: visual brand brief

Source: none. Two web searches on 2026-11-15 ("Premise" story development tool, and "Premise" "Figma for Hollywood") found no public site, logo or product screens, and Wellfound is never opened. So this page does not borrow a brand. It uses a restrained look drawn from the world the product serves: the screenplay page.

## Canvas
Warm paper. Page `#FBF8F2`, intro and contact bands a shade deeper `#F3ECDF`. Ink `#24201B` (warm near-black, like a fresh photocopy), muted text `#5E554A`, rules `#E4DACB`.

## Type
- Display: `Newsreader` 400, a quiet book serif for headlines, tight but not cramped.
- Text: `Instrument Sans`, plain and readable at 16 to 18px.
- Script: `Courier Prime` 400/700 for anything that is part of a page of script (scene headings, character cues, dialogue). Korean falls back to the system Hangul face.

## Colour
- Buttons: ink fill `#24201B` with paper text, 3px corners, like a typed label.
- Pencil red `#9A3A26` for margin notes and revision marks only, never as a band.

## Shape
Square-ish: 3px button corners, 4px on the script page, thin 1px rules. No shadows except a faint one under the script page so it reads as paper.

## Signature details
- A script page with a page number in the top right corner and a revision asterisk in the margin.
- Scene headings in caps Courier, character cues centred.
- Margin notes in pencil red.

## For our page
1. Paper canvas, Newsreader headlines at 400.
2. Ink buttons with 3px corners.
3. The opening object is a script page: four scenes from my work, English or Korean.
4. No logos, no invented brand marks.
